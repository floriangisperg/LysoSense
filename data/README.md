# data/ — measurement data (local, gitignored)

Proprietary raw + processed measurement data, OneDrive-backed, not tracked in
git (only these README maps are). Provenance ledger with hash-verification
status and operator-note translations:
**[docs/DATASETS.md](../docs/DATASETS.md)**.

| Folder | What it is |
|---|---|
| `HMS_data/` | Executed HMS campaign (Small EXP 1/2/3, Daten Pilot V302/V303, Small_700, Bench DEVOPS V224) — **canonical**; the sibling Homogenisation repo mirrors a verified subset |
| `CPS-FACS/` | FACS campaign: CPS `.dat` + FACS `.fcs` raw (Demo/Eng1/Eng2); `CPS/Demo` backs the pytest golden tests |
| `cps_archive_2024_2025/` | Raw CPS exports from 2024–2025 campaigns; referenced by no code |
| `rollout-demo/` | Curated 8-file demo bundle (byte-identical subset of the rows above) |

Rules:

- Never rename or delete raw instrument files (`.dat`, `.fcs`) — filenames
  are parsed downstream and are provenance.
- `lysosense_summary*.xlsx` files inside `HMS_data/` are generated by the app
  but consumed by the Homogenisation loader — do not move or regenerate
  casually (see DATASETS.md).
- German operator notes (`ACHTUNG…`, `Immer 700 bar.txt`) are provenance —
  kept verbatim, translated in DATASETS.md.
