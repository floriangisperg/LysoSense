# cps_archive_2024_2025 — raw CPS export archive

89 raw CPS `.dat` exports plus one `export.ctr` instrument control file from
2024–2025 campaigns (G7 series, V301–V307 pilots, D23–D25 series).

Referenced by no code (verified 2026-11-20) — kept purely as measurement
provenance. Renamed from `test-data/` on 2026-11-20; nothing downstream
depends on the name. See [../../docs/DATASETS.md](../../docs/DATASETS.md).
